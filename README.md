<h1 align="center">史莱姆冰</h1>
<p align="center"><p align="center">MD3风格安卓音乐播放器</p>

> 史莱姆冰是一个使用Flutter语言编写以美观为主的Android用户音乐播放器。由于只是itnproject制作的第一个由Flutter语言编写的Android应用，出现bug可以在Issues提交问题，你的提交是修复bug的最大帮助！

# 项目介绍
* 这是什么：一个使用Flutter语言编写以美观为主的Android用户音乐播放器。
* 有何不同：
  * 根据音乐动态取色
  * 拥有MD3风格
  * Flutter强性能
* 支持语言：简体中文和English

# 项目帮助
#### 我的Android设备为什么安装不了/打不开？
答：史莱姆冰最低支持Android11。
#### 我在使用时出现问题怎么反馈？
答：提交Issues。最好截图，描述完全。

> [!TIP]
> 太猎奇的问题不要提交Issues，以免引人嘲笑😂
